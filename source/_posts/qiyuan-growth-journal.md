我想让自己做过的事情有地方安放，也想看清：今天的一点投入，正在为怎样的生活打基础。

于是，我把“七元极意”中的七项日常法则整理成了行动台，又补上一个记录长期资源建设的成长空间。这篇《七元成长手记》，就来介绍它们现在的样子。

![七元成长手记概念导览：七项日常法则与九项长期资源](/images/qiyuan-growth-journal/01-cover.png)

*概念导览：日常行动与长期建设，是观察生活的两个视角。*

> 热情是动力，秩序是保障。持续建设一个能够支持自己生活的系统。

## 先让今天的一件小事，有处安放

日常部分使用的是“七元极意行动台”。左侧放着七项法则，中间是一周七天的行动安排，上方汇总本周事项、完成数、涉及的类别与完成率。

![七元极意行动台已保存的发布界面：侧栏分类、周统计和七日安排](/images/qiyuan-growth-journal/02-interface.png)

*真实发布截图：界面保留现有名称“七元极意行动台”。日期与空白统计为截图保存时的状态。*

添加事项时，只需要写清楚具体做什么、安排在哪一天，再选一个类别。完成后勾选，想修改时点击事项文字。也可以切换周次，或者按类别筛选，回看自己的时间和精力都落在了哪里。

| 日常法则 | 可以放进去的具体行动 |
| --- | --- |
| 学习 | 看一小段课程，解释一个知识点 |
| 阅读 | 读几页书，记下一个真正想追问的问题 |
| 形体锻炼 | 安排一次力量练习或轻柔舒展 |
| 作息 | 记录吃饭、休息与睡前收尾的安排 |
| 友爱环境 | 整理桌面，或为一次友善的交流留时间 |
| 解决难题 | 把困扰写清楚，确定一个可尝试的下一步 |
| 欲望 | 给游戏、创作、好奇和喜欢的事留出位置 |

我希望这些分类提醒自己照顾生活的不同部分。界面也留着一句话：“不必填满每一格，行动自有节律。”

## 再看看：这些行动，正在建设什么

有些事情需要按天安排；有些积累，要过一段时间才能看清。资源成长系统把长期方向分成三组、九项，让我为每个方向分别写下当前状态、理想状态、长期方向和下一步行动。

![资源成长系统的三组九项资源：生存、发展与社会资源](/images/qiyuan-growth-journal/03-resources.png)

*功能结构示意：分类来自现有系统，图中没有虚构个人的进度或成果。*

每项资源可以记录“未启动、探索中、建设中、稳定积累、持续维护”等阶段。它们由自己判断和更新，也允许归档、调整和重新开始。总览中的行动次数与产出记录，帮助回看实际留下了什么。

| 功能页面 | 可以做的事 |
| --- | --- |
| 总览 | 查看九项资源、本周记录与已明确的下一步 |
| 资源地图 | 浏览内置的资源联系路径，进入相应的建设档案 |
| 行动记录 | 记下日期、行动、产出、经验、问题与改进方向；按条件筛选 |
| 阶段目标 | 把目标拆成里程碑，逐项勾选，记录阶段完成或归档 |
| 周期复盘 | 按周或按月回答问题，保存对方法与下一步的判断 |
| 资料库 | 保留作品说明、成果链接和小附件，方便回看 |
| 设置 | 切换明暗主题，导出或恢复资源成长记录 |

资源地图当前提供几条预设路径。例如“信息来源—学习体系—行动成果—收入来源”，用来帮助思考不同资源可能怎样相互支持，具体的选择与建设仍由自己完成。

## 用一个小例子，把流程走一遍

假设我想建立更清楚的学习体系，可以先把下一步缩小成“整理一个知识点”。做完后，记下自己实际完成了什么，把知识卡片留进资料库，再在周复盘中回看：哪里理解得更清楚了，什么方法值得继续用。

![从建设档案到行动记录、成果保存与周期复盘的使用流程](/images/qiyuan-growth-journal/04-workflow.png)

*使用流程示意：让一次具体尝试，留下可回看的结果。*

周期复盘里，我尤其想保留两个问题：“哪些事情产生了实际成果？”以及“下一周期最值得投入的事情是什么？”它们能把记录重新带回下一次选择。

## 让这个空间适合自己，也照顾好记录

行动台支持预设主题色和自定义颜色，资源成长页可以切换浅色与深色。颜色只是一个小细节，但我希望这个经常打开的空间能让人待得舒服。

当前版本的记录保存在此设备、此浏览器的本地存储中，不会在不同浏览器之间自动同步。七日行动与资源成长分别备份；更换设备、清除站点数据之前，需要分别导出 JSON，再在相应模块恢复。

这套工具目前用于个人记录。我希望它能让我看见今天做过的事，也看见一点点正在形成的积累。每天从一个具体行动开始，过一段时间，再回来看看自己留下了什么。
